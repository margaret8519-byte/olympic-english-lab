# Speaking 2022 source report

Официальный источник: локальные PDF из `olympic-english-lab-references/source_materials/grade-7-8/2022/speaking`. Несмотря на имя каталога `grade-7-8`, сами документы однозначно помечены как материалы муниципального этапа 2022 года для 9–11 классов.

## Найденные карточки

- `card_52_1668950470.pdf` — Student 1, Set 1: Moscow Zoo.
- `card_52_1668950482.pdf` — Student 2, Set 2: London Zoo.
- `card_52_1668950501.pdf` — Student 1, Set 3: San Diego Zoo.
- `card_52_1668950513.pdf` — Student 2, Set 4: Singapore Zoo.

Все карточки задают 10 минут подготовки, монолог 3–4 минуты, вопросы/ответы 2–3 минуты и пять обязательных тематических аспектов.

## Fact Files

- Moscow Zoo: найден полный Fact File в `file_52_1668950768.pdf`; перенесён в структурированные секции без добавления внешних фактов.
- London Zoo, San Diego Zoo, Singapore Zoo: Fact Files среди предоставленных файлов отсутствуют. Наборы помечены `needsFactFile: true` и заблокированы.

## Оценивание

- `criteria_52_1668949675 (1).pdf` — официальные критерии.
- `file_52_1668949376.pdf` — дополнительная схема оценивания.
- Максимум: 20 баллов (монолог 6, диалог 5, организация 3, лексика 2, грамматика 2, фонетика 2). При 0 за коммуникативную задачу монолога итоговая оценка равна 0.

## Реализовано

Выбор набора, блокировка неполных материалов, настоящий countdown подготовки, ранний переход к ответу, Fact File, обязательные аспекты, заметки только на подготовке, разрешение микрофона, реальная запись MediaRecorder, таймер и waveform, остановка и освобождение микрофона, audio player, подтверждение перезаписи, локальное сохранение только метаданных в `speakingAttempts`, формальная проверка длительности, результат и интерфейс официальных критериев.

## Требует будущего AI/backend

Языковая оценка содержания, взаимодействия, организации, лексики, грамматики и произношения не симулируется. Диалог с партнёром/AI interviewer и облачное хранение записи не подключены. Audio Blob существует локально только в пределах текущей попытки; на сервер ничего не отправляется.
