## Правила импорта

1. `source: official-vsosh-vzlet` — только для задания, сверенного с официальным источником.
2. Авторские задания: `source: original-olympic-english-lab`, `stage: training`, `platformLabel: OLYMPIC ENGLISH LAB`.
3. Автопроверка включается только при наличии подтверждённого официального ключа.
4. Writing не получает выдуманный автоматический балл: итоговая оценка выставляется после проверки.
5. Listening считается безопасным только при совпадении задания, ключа, скрипта и исходного аудиофайла.
6. Нельзя менять официальную группировку классов конкретного года: например, 2024/2025 — общий вариант 9–10.
7. Сокращённый или пересказанный passage не должен маркироваться как точный официальный вариант.
